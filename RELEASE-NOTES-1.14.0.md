PC Tweaker 1.14.0 rebuilds Windows integrity check and repair around one panel that moves from ready, to running, to a result that asks whether to repair. Shrinking the component store now sits apart as maintenance, instead of next to the check where it read as a second way to fix Windows.

The check is faster when there is something to find. It first asks DISM for the damage Windows already has on record, which takes seconds, and stops there if any is found; only a clean answer goes on to the full scan. Repair anyway after a clean check runs the system file check alone, without first restoring a component store the check has just verified.

While a job runs you see the percentage over time, every step with how long it took, the time left and the expected finish. Estimates start from typical durations and learn how long each step takes on your PC. When DISM holds the same percentage for minutes, as it routinely does, the panel says so instead of looking frozen.

Windows application and installer signatures are verified before distribution. Code signing identifies the publisher; Windows may still show reputation warnings.
