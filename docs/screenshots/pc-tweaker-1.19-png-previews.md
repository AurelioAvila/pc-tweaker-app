# PC Tweaker 1.19 interface previews in PNG format

These PNG files contain the same decoded pixels as their published JPEG counterparts:

- `pc-tweaker-1.19-interface-sample-data.png`: Scan entry screen.
- `pc-tweaker-1.19-scan-results-sample-data.png`: Sample scan findings.
- `pc-tweaker-1.19-hardware-audit-sample-data.png`: Sample hardware and driver-date findings.

The visible **INTERFACE PREVIEW — SAMPLE DATA** footer is preserved. The images illustrate the 1.19 interface using synthetic readings; they are not native Windows measurements, benchmarks or evidence of performance gains. No settings, drivers or firmware were changed to create these previews.

The file-format conversion supports catalogs that require PNG. It does not change the application or the image content.
