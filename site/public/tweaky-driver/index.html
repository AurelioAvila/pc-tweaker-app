Before you download

Which Windows versions are supported?

The application targets Windows 10 and Windows 11 on x64 systems. Check the latest release notes for current requirements and known limitations.

How can I verify a download?

Download from the official GitHub release. In Windows file properties, check that the digital signature is valid and identifies Aurelio Avila. Compare the SHA-256 with the official asset digest when available. Code signing does not guarantee that SmartScreen will never display a warning.

Is this an open-source application?

No. Tweaky Driver is proprietary. Its public repository contains distribution information and release notes; the application source is private. Third-party components retain their own licenses.

Where can I find current plan information?

See Plans above. You subscribe from the app's plans screen, where the final amount and renewal terms are shown before you confirm. This website does not collect payments.

How do I report a problem?

Use Report an issue in the application or email tweakydriver@pctweaker.app. Include your app version, Windows version and reproduction steps, but never passwords or license tokens.
